Spiel einrichten

Kaufleute, Koggen und die Pest · etwa 15 Minuten · Häkchen setzen, wenn erledigt

1. Firebase-Projekt (Bildschirm 1, Browser)

2. Regeln setzen

{
  "rules": {
    "spiele": {
      "$code": {
        ".read": true,
        "status": { ".write": true },
        "spieler": { "$id": { ".write": true } }
      }
    }
  }
}

3. Web-App registrieren

Prüfen: Im Block steht eine Zeile databaseURL. Fehlt sie, wurde Schritt 1 (Realtime Database) übersprungen. Der Block ist kein Passwort.

4. Online stellen (Bildschirm 1, GitHub Desktop)

Erst machen, wenn Claude die Firebase-Daten eingetragen hat.
